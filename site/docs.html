Make an extension

Extensions (we call them that, not plugins) add themes, snippets and commands to Stride. You need no build tools — just a JSON file and, if you want, a bit of JavaScript.

Quick start

  1. Open the Extensions panel (Ctrl+Shift+X) and press Build your own extension.
  2. Give it a name. Stride creates a folder with a working example and opens main.js.
  3. Edit the code and save. Stride reloads the extension instantly.
  4. Press Ctrl+Shift+P and find your command — it is listed under your extension's name.

Tip: the five built-in extensions (Word Count, Case Converter, Sakura Theme, HTML Starter Snippets, AI Commenter) are examples. Choose Copy to my extensions in their menu to get an editable copy.

The folder

Your extensions live in the Stride data folder (Extensions panel → ⋯ → Open extensions folder). Each one is a folder whose name is the extension id:

extensions/
  my-extension/
    extension.json   ← description: name, commands, themes, snippets
    main.js          ← optional code

extension.json

FieldWhat it is
idUnique id: lowercase letters, digits and dashes (word-count). Must match the folder name.
nameName shown in the editor.
versionLike 1.0.0. Raise it when you publish an update.
descriptionOne or two sentences about what it does.
authorYour name.
iconOptional M3 shape: cookie9, clover4, sunny, flower, pentagon, gem, softBurst, pill…
categoriesAny of Themes, Snippets, Tools, AI, Formatters, Fun.
permissionsOptional: ai, network, clipboard. See Permissions.
mainOptional JavaScript file, usually main.js.
contributesOptional themes, snippets and commands.

Themes

A theme is described by two colors in OKLCH: a neutral for backgrounds and an accent. Stride generates the full palette for light and dark mode, including code colors.

{
  "id": "sunset-theme",
  "name": "Sunset",
  "version": "1.0.0",
  "description": "Warm orange accent on soft sand.",
  "author": "You",
  "categories": ["Themes"],
  "contributes": {
    "themes": [{
      "id": "sunset",
      "name": "Sunset",
      "neutralHue": 60, "neutralChroma": 0.02,
      "accentHue": 40, "accentChroma": 0.15,
      "syntaxChroma": 0.12
    }]
  }
}

Hue is 0–360, neutral chroma 0–0.04, accent chroma 0–0.2. Your theme appears in Settings → Appearance next to the built-in presets.

Snippets

Snippets show up in autocomplete when you type the prefix. Use $1, $2 for places the cursor jumps to with Tab, ${1:default} for a placeholder and $0 for the final cursor.

"contributes": {
  "snippets": [{
    "language": "python",
    "prefix": "main",
    "description": "if __name__ == '__main__'",
    "body": ["def main():", "    $0", "", "if __name__ == \"__main__\":", "    main()"]
  }]
}

Commands

Declare the command in extension.json and register what it does in main.js:

"main": "main.js",
"contributes": {
  "commands": [{ "id": "shout", "title": "Shout Selection", "keybinding": "ctrl+alt+u" }]
}
// main.js
stride.commands.register("shout", async () => {
  const text = await stride.editor.getSelectedText();
  if (!text) return stride.window.showMessage("Select some text first.", "warning");
  await stride.editor.replaceSelection(text.toUpperCase() + "!");
});

The command appears in the Command Palette (Ctrl+Shift+P). keybinding is optional.

The stride API

Your code runs in a separate sandbox and talks to the editor through the global stride object. Almost every call returns a Promise — use await.

CallWhat it does
commands.register(id, fn)Runs fn when the command is chosen.
editor.getText()Text of the open file.
editor.getSelectedText()Selected text (empty string if nothing is selected).
editor.getLanguage()Language id, e.g. "python".
editor.getFileName()File name, or null when no file is open.
editor.replaceSelection(text)Replaces the selection.
editor.insertText(text)Inserts text at the cursor.
editor.setText(text)Replaces the whole file (can be undone with Ctrl+Z).
window.showMessage(text, kind?)A notification; kind is "info", "success", "warning" or "error".
window.showQuickPick(items, placeholder?)A list to choose from. Items are strings or {label, description, value}. Returns the value or null.
window.showInput(prompt, value?)Asks for text. Returns it or null.
statusBar.set(text, tooltip?) / clear()Your item in the status bar.
events.onDidSave(fn)Called with {fileName} after a file is saved.
events.onDidChangeActiveEditor(fn)Called with {fileName, language} (or null) when another file becomes active.
events.onDidChangeText(fn)Called (debounced) when the text changes.
storage.get(key) / set(key, value)Saves small JSON values between restarts.
clipboard.writeText(text)Copies text. Needs clipboard.
ai.complete(prompt, system?)Asks the AI the user set up and returns the answer as text. Needs ai.

Permissions

By default an extension can only read and edit the open file and show UI. It has no internet access and cannot touch your disk. Extra abilities need a permission, and Stride asks the user before installing:

  • ai — use stride.ai.complete. The user's API key is never given to the extension.
  • clipboard — use stride.clipboard.writeText.
  • network — use fetch and other web APIs.

Examples

Every Workshop extension is a readable example. Good places to start:

  • Word Count — events and the status bar.
  • Case Converter — quick picks and editing the selection.
  • Sakura Theme — a theme without any code.
  • HTML Starter Snippets — snippets without any code.
  • AI Commenter — using AI.

An AI command in a few lines:

stride.commands.register("explain", async () => {
  const code = await stride.editor.getSelectedText();
  const answer = await stride.ai.complete("Explain this code in one sentence:\n" + code);
  await stride.window.showMessage(answer);
});

Publish to the Workshop

  1. In Stride open Extensions, press ⋯ next to your extension and choose Publish to the Workshop… Or drop the folder on the Publish page.
  2. GitHub opens with your extension filled in. Press Create — you need a free GitHub account.
  3. A bot checks the format within a minute. If something is wrong, edit the issue and it checks again.
  4. @cleveroze reads the code and permissions and approves it. The extension appears in the Workshop — in Stride and on this site — about a minute later.

To publish an update, raise version in extension.json and publish again. Only the account that published an extension first can update it.

To share privately, just send the folder — your friend puts it into their extensions folder. Any .stride-ext.json file downloaded from the Workshop can also be installed with Extensions → ⋯ → Install from file….
