Extension SDK guide

Submitting opens a GitHub issue under your signed-in account. An issue is a review request, not an instant publication.

How approval works

  1. Sign in to GitHub and submit your extension details.
  2. Prepare the extension files in your repository. Include extension.json and any required script.
  3. Open a pull request adding the folder to extensions/<id>/.
  4. The repository owner reviews permissions, source and behavior.
  5. Once the pull request is approved and merged, the Workshop catalog is rebuilt and the extension goes live.
View review queue ↗

Only maintainers with repository merge permission can approve publication. Closing a request without merging does not publish the plugin.
